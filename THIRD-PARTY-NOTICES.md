# Third-party notices

lanthorn itself is BSD-3-Clause (see `LICENSE`). Its three virtual-machine
crates take no external dependencies at all, and the crates that do pull theirs
from crates.io under the usual permissive terms.

Two *data* sources are different: their licences require a notice to travel with
anything derived from them, and `crates/verb-synonyms/src/synonym_groups.tsv` is
derived from both. That file is generated by `crates/verb-synonyms-gen`; neither
corpus is vendored into this repository.

That table has a third input with no licence question attached, recorded here
because provenance is what makes a generated file auditable: roughly a fifth of
its groups are read out of the GRAMMAR TABLES of 119 interactive-fiction story
files — which spellings each game's own author declared to be one verb. No game
file, game text or game title is redistributed; what is committed
(`crates/verb-synonyms-gen/if_groups.tsv`) is a de-duplicated list of English
verb sets with a count of how many stories declare each. The corpus itself is
not in this repository (`stories/` is gitignored).

## 12dicts 6.0.2 and AGID — Alan Beale, Kevin Atkinson

The frequency ranking and the lemmatisation used to build the same table come
from `Lemmatized/2+2+3frq.txt` in Alan Beale's 12dicts package, version 6.0.2.
Beale releases the 12dicts lists into the public domain but notes that the
`2+2+3` lists depend on Kevin Atkinson's Automatically Generated Inflection

> The 12dicts lists were compiled by Alan Beale. I explicitly release them to

## IosevkaTerm Nerd Font Mono — Renzhi Li; Nerd Fonts (Ryan L McIntyre)

The Docker image (`Dockerfile`, `font-fetch` stage) embeds two faces of
**IosevkaTerm Nerd Font Mono** — Regular and Bold, converted to WOFF2 — in the
browser page it serves, so lanthorn's Nerd Font icons and the automap's Legacy
Computing half-diagonals render without depending on a visitor's installed
fonts. Nothing in this repository or in the native binaries contains the font;
it is fetched at image build time from the Nerd Fonts v3.5.1 release
(`IosevkaTerm.zip`, SHA-256 pinned in the Dockerfile) and shipped only inside
the image, under `/usr/local/share/lanthorn/fonts/`.

- **Iosevka** (the typeface, version 34.8.0 in that release) is
  Copyright (c) 2015-2023 Renzhi Li (aka Belleve Invis) and licensed under the
  **SIL Open Font License, Version 1.1**. The OFL permits bundling and
  embedding with software provided the licence accompanies the Font Software,
  so the release's `LICENSE.md` (the full OFL text) is copied into the image
  beside the font files.
- **Nerd Fonts** patches Iosevka with icon glyphs; the patcher itself is MIT.
  The icon sets it merges carry their own terms, recorded in the release's
  `README.md`, which the image ships beside the licence for attribution:
  Codicons and Font Awesome (CC BY 4.0), MaterialDesign (Apache 2.0), Weather
  Icons and Pomicons (OFL 1.1), Devicons, Octicons, Seti, Powerline and the
  Hack extra glyphs (MIT), Font Logos (unlicensed).
