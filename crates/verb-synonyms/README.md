# lanthorn-verb-synonyms

A bridge from a word a player typed to one an interactive-fiction story
actually knows, for the classic "guess the verb" problem (`illuminate` → `light`)
that edit distance, stemming and grammar shape all miss. Ships a small,
generated table of synonym groups and irregular inflections, derived from real
IF vocabulary and WordNet.

It is used by [lanthorn](https://github.com/sharkusk/lanthorn) to power its
in-game vocabulary hints.
