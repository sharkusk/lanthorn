# lanthorn-grammar-model

Shared, dependency-free answer types for "what can a player type here" —
verbs, syntax lines, noun kinds, object vocabulary and adjectives — returned
by both the Z-machine and Glulx grammar readers so a caller asks one question
of either format.

It is used by [lanthorn](https://github.com/sharkusk/lanthorn)'s `zvm` and
`gvm` engine crates.
