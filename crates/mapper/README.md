# lanthorn-mapper

A VM-agnostic, serializable map model for interactive fiction: rooms,
connections, layered 2-D layout, overlap removal and edge routing, built from
a stream of "where you are" / "which way you went" events rather than from
any particular game engine.

It is the automapping engine behind
[lanthorn](https://github.com/sharkusk/lanthorn), a terminal
interactive-fiction player with live automapping.
