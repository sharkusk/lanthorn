# lanthorn-blorb

Blorb container parsing (bundled story data, cover art, sound and image
resources) plus readers for original Infocom release media: Amiga `.adf`,
Macintosh DiskCopy/HFS, DOS and Atari ST FAT12 floppies, Apple II ProDOS and
raw self-booting disks, and Commodore 1541 `.d64`/`.g64` images.

It is the resource and disk-image layer behind
[lanthorn](https://github.com/sharkusk/lanthorn), a terminal
interactive-fiction player with live automapping.
