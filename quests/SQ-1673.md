--- note 2026-10-02T02:32:48Z ---

Root cause, reproduced headlessly with real Zork I r88 in the Troll Room:
- "use" is unknown to Zork I.
- by_meaning (crates/app/src/vocab.rs:842 -> :959) finds exactly one known word in use's WordNet meaning groups, "apply". It is vetted in the silent copy: "apply sword on troll" -> "That sentence isn't one I recognize." -> rejected -> nothing delivered (vocab.rs:2242 deliver).
- SQ-1642's grammar-shape scan (by_grammar_shape, vocab.rs:1080; commit 810c072e) never runs, because it only runs when earlier sources returned nothing. Tangle worked only because no word in use's meaning groups is in Tangle's dictionary.
- Not Inform-only: Zork I's ZIL grammar scans fine ("_ troll with sword" -> unlock/flip/chuck).
- Second gap: the shape scan matches the typed shape literally, so it can't reach "attack troll with sword" (operands swapped, preposition on -> with). MAX_SHAPE_CANDIDATES = 8 (vocab.rs:788) truncates in verb-table order, which could also cut "attack".

Proposed fix:
(a) When vetting rejects every pick from earlier sources, fall through to the grammar-shape scan as a second round (second probe, or merged within MAX_PROBES = 16, probe.rs:158).
(b) "use A on/with B" idiom: also scan "V B with A" shapes and vet them as full commands.
(c) Rank, don't truncate in table order.
Tests: vocabulary_vetting Zork I Troll Room "use sword on troll" -> a vetted attack/kill troll with sword; Tangle "use lockpick on plate" stays green.

--- note 2026-10-02T02:42:14Z ---

Maintainer decision 2026-10-01: the swapped-operand idiom applies to a fixed list of generic tool verbs (use, utilise, utilize, employ, wield, operate), not "use" alone, and not every verb, because vetting proves only that a sentence parses, not that it makes sense. It goes through the same by_grammar_shape path as SQ-1642's tangle.z5 fix, so tangle gets the fall-through, the idiom and the ranking too.

--- note 2026-10-02T02:43:11Z ---

Rationale (maintainer): this serves players coming from graphical point-and-click adventures, where one generic "use" button was overloaded for every action. Translating "use X on Y" into the story's own verb is a primary onboarding path, not an edge case, so don't trim the tool-verb list without that in mind.
