## What the capture settles

* **The story window is a real primary `Buffer`** (`attrs=1111`, `model: Buffer`), so SQ-1026's promoted-grid guard is not involved — the same finding as SQ-1056.
* **`0 prose line(s)` and `0 paint run(s)` on win0.** The clue text is not in the model as window content; in raster the prose comes from the HOST transcript through `build_main_text`. So the "random text" bleeding through is almost certainly *scrollback* — the transcript re-wrapped into the story box — rather than anything the game drew.
* **The face is Geneva 12, proportional, 3–11 px against a declared 7.** Same press as SQ-1054.
* **Same session shape as SQ-1056**: a long run of `hybrid-ring` frames and modal overlays, then `raster`.

## The user's own read, which is the useful part

> this along with 1056 shows we have some screen contention entering and exiting out of the hint menu system. perhaps the type of window changes? However, the fact that hybrid works shows that we are not following the same logic, so we may want to start by eliminating the duplicate logic between hybrid and raster when it comes to window management, clearing, etc.

That is worth taking seriously as the framing rather than treating this as a third isolated bug. **SQ-1056, SQ-1069 and SQ-1070 are all raster-only failures on the InvisiClues path**, and hybrid is right in every one. The two paths do already dispatch differently on the story surface — `render_node` sends a `Buffer` to `render_transcript` and a `Grid` to `draw_grid`, while `build_v6_raster_canvas` has its own chain of early-return arms plus the guard SQ-1026 added — and that duplication is exactly the shape CLAUDE.md's refactoring policy names.

**Do not start by unifying them.** Establish first, on one frame, *which* decision the two paths make differently — the clear, the story box, the prose source, or the scroll — and fix that. Then judge whether the remaining duplication should become one owner. A rewrite driven by "hybrid works and raster doesn't" without knowing which branch diverges is how the last several of these went wrong.
