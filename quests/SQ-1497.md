--- note 2026-09-16T18:18:05Z ---

Correction found by the SQ-1524 investigation, 2026-09-16: `decode_line_art_opening`'s premise was wrong. The Atari line-art format is NOT the Apple II item-26 grammar — it's fixed three-byte tokens on a 160x96 GRAPHICS 7 canvas. What this function decodes as "the same small picture on every title" is actually a mid-stream fragment of the darkness card's record, decoded under the wrong grammar, which is why it happened to look identical across four different games (it was decoding noise the same way each time, not real shared art). Real per-room content exists and its index is now known (SQ-1524, shipped), but nothing can actually be drawn until the true token grammar is decoded — tracked as SQ-1525. This quest's shipped code is harmless (never wired into gameplay, SQ-1497 deliberately stopped short of that), but should not be treated as a working decoder or reused as a reference.

--- note 2026-09-17T01:00:56Z ---

Closing 2026-09-17: the original goal (draw all four Atari line-art titles) is fully achieved, via the chain SQ-1524 (found the real picture index) → SQ-1525 (decoded the real token grammar, this quest's own decoder having turned out to be wrong) → SQ-1526 (hi-res supersample) → the wiring commit (9b7777e8) that put it in front of the player for all four titles. SQ-1497's own shipped code (decode_line_art_opening/LINE_ART_OFFSET) was retired as part of that chain, confirmed gone from crates/scott/src — nothing references it except comments explaining why it was wrong.
