Repro: Zork I (zork1-r88-s840726.z3), from West of House type `north`. The game prints the room heading `North of House`; `game_echoes_command` decides the game echoed the command and the host suppresses its own echo line, so the transcript shows no record of what the player typed. Reproduces in the TUI and through the session host.

Expected: only a genuine echo of the command (the game repeating the input line itself) suppresses the host's echo; a room heading, or any output that merely begins with the same word, does not.

Acceptance: a test in tests/suites/host_turn.rs (skip when the story is absent) that walks `north` from West of House and asserts the command echo line is present; the existing self-echoing-game cases (e.g. the SQ-0275 family) still suppress the duplicate.
