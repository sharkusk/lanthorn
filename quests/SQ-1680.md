--- note 2026-10-02T19:41:34Z ---

Design 2026-10-02 (maintainer + coordinator):
- UI: like the story downloader. A "Download documents from IFDB" action on the story info panel opens a chooser over the game's viewgame?ifiction links (the same request the story downloader makes), with multi-select. Downloads land in the SQ-1679 folder via documents::import (created on demand, clash suffix, atomic).
- Eligible: non-<isGame/> links, by URL extension (authoritative):
  - pdf;
  - images: png/jpg/jpeg/gif/webp/tif/tiff;
  - text: txt/doc/rtf/md, plus extensionless when IFDB format is text/document;
  - zip (see below).
- Excluded: games, setup/executables (.exe/.hqx), audio, html pages, .inv (they belong to the existing Shift-H hint downloader, hint_download.rs).
- Spoiler tag (APPROVED): links under /solutions/ or /hints/ are marked "spoiler" in the list.
- Size cap about 50 MB per file (APPROVED); follow only IFDB-listed links.
- Zips, verified feasible 2026-10-02: ifarchive.org (direct and via the www mirror redirect) answers Range requests with 206. Fetching the last 64 KB of Sols1.zip (218 KB) yielded the whole central directory: 57 entries, names and sizes, without downloading the archive. app already depends on zip 2, flate2 and ureq.
  - So a zip row can expand to its contents before downloading, and individual entries can be range-fetched and inflated alone. E.g. take only "ZorkI" from Sols1.zip, which is a 57-game solutions bundle.
  - Fallback when a server doesn't support ranges: "contents unknown", whole-zip download only.
  - Pending maintainer: whole-zip download as well as per-entry; text-entry preview in the chooser; highlighting entries whose name matches the game title.

--- note 2026-10-02T19:44:56Z ---

FINAL PLAN (maintainer approved 2026-10-02):
- Entry points (all go through one registry command, `download-documents`, Context::Browser plus in-game):
  - a "[ Download documents… ]" button on the story info panel's Documents line;
  - a story-menu row "Download documents from IFDB…";
  - Shift-D in the browser (pairs with Shift-H download-hints; plain d stays reverse-sort);
  - in-game `/download-documents` for the current game.
  - Unlinked game: disabled button/row reading "Link to IFDB first"; key and command report the same on the status line.
- Chooser: like the story downloader, multi-select, over the game's viewgame?ifiction links (no extra request beyond the existing one).
  - Rows show filename, IFDB title/desc subtitle, kind and size when known.
  - Spoiler tag for /solutions/ or /hints/ paths.
- Eligible: pdf; png/jpg/jpeg/gif/webp/tif/tiff; txt/doc/rtf/md; extensionless when the IFDB format is text/document; zip.
- Excluded: isGame links, executables/setup/stuffit, audio, html, .inv (Shift-H owns those).
- Zips:
  - expand to their contents via HTTP Range (central directory only), with fallback "contents unknown" and whole-zip only;
  - whole-zip download AND per-entry extraction (range-fetch + inflate only the chosen entries);
  - entries matching the game title are highlighted;
  - text entries can be previewed (first lines, fetched alone).
- Limits: about 50 MB per file; only follow IFDB-listed URLs.
- Writes go through documents::import (folder created on demand, clash suffix, atomic).
- IFDB ToU: user-driven, one request in flight, descriptive User-Agent (reuse ifdb_search's).
