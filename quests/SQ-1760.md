--- note 2026-10-10T06:19:35Z ---

Today render/transcript.rs truncate_status_text is pub(crate) inside render/, and counts terminal columns. A host that measures text in its own units needs the same rule without columns: e.g. a pub fn in a non-render module that, given the room text and a fits(&str)->bool predicate (or a list of candidate cut points), returns the shortened string (last space before the overflow, trimmed, plus '…'; hard break when a single word overflows; unchanged when it fits). The TUI's column version can call it with fits = chars().count() <= width, so both share one rule. Tests: fits unchanged; breaks at last space; single long word hard-breaks; width 0 / nothing fits.
