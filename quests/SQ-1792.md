  An embedding host that reads player commands (e.g. typed in another language, or spoken) needs to choose between a verb's 'put X in Y' and 'put X on Y' grammar lines when the input doesn't say which. Today ObjectWords (crates/grammar-model/src/lib.rs:649) and the Introspect trait (crates/app/src/engine.rs:541) expose no container/supporter attribute; only the debug object_detail (engine.rs:735) prints attributes. Ask: add to ObjectWords (or a small Introspect method) whether each in-scope object is a container and/or a supporter (and open/closed if cheap), for Z-machine (Inform's container/supporter attributes; Infocom's CONTBIT/SURFACEBIT where identifiable) and Glulx, None where unknown (Scott Adams).
