--- note 2026-10-24T16:04:34Z ---

Since SQ-1814 (87af3cf36), a v6 chrome text strip that overruns drops all-blank columns via upper_window::strip_column_plan, and strip_run_positions/strip_run_resolution/strip_divider_fills map runs through that plan. But build_hybrid_click_map is still called with the pane scale only: crates/app/src/render/screen.rs:6236 (V6HybridChromeLayout::click_map, used by embedding hosts) and :1404 (the TUI's record_hybrid_click_map). Once a strip drops columns, a clicked cell must be mapped back through the plan (add back the columns dropped before it) before the scale inverse. Repro: Journey (PC) in a 390x700 px pane at DPR 2 (cell 10.2x22.95 px), Start -> Cast -> Elevation; clicking 'Esher' at cell [31,26] does nothing. It worked at d50ae40a3. Affects the TUI and any host that uses the hybrid chrome layout's click map.
