--- note 2026-10-12T03:28:39Z ---

Design settled with user 2026-10-11.
- Trigger: first visit to a room; worker-thread shadow from that moment. `look` control first (as SQ-1771). Then each of the 8 compass points, u/d, in/out, plus ship words the story's dictionary holds. Each from a freshly restored state. A death is not a landing.
- Landing in a room the map holds: record the verified passage (as the return probe does). Landing somewhere new: record "an exit leads this way" WITHOUT the destination's name or any detail about it (user: never reveal the room). No room change: not an exit now.
- Revisit: rescan only the directions that failed before (doors open, puzzles solved). Don't infer meaning from refusal wording.
- Show ALL found exits, including ones the description never mentions (user decision).
- The map's "unexplored exits" (`MapGraph::untried`, driven by the player's `tried` record) should become real exits not yet walked for a scanned room; keep the player-tried vs probed records separate (return_probe.rs "Two records" rule).
- Setting: ON by default, with a config option to turn it off (config_template + docs + `write_config` conventions; any new map mark styleable via style.toml).
