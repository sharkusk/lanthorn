Supporting detail worth keeping: the message lands on the BOTTOM line, not the top. If the erase reset the cursor, a freshly-cleared window would print at the top. Bottom placement says the cursor survived the erase — so the suspect is an erase of the wrong window, or an erase that legitimately spares the cursor while lanthorn wipes more than the game asked for.
