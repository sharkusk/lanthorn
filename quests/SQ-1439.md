Coordinator note 2026-09-09: reframed — the likely defect is deeper than a missing signal. The VFS models the game's DISK; a real Glk library's files survive a Glulx @restart (glulxe's vm_restart reloads memory and the stack and leaves Glk objects alone; the spec's @restart entry says nothing about files). So `self.glk = Model::new()` in op_restart should not discard file contents at all — Counterfeit Monkey's startup-data file would vanish on an in-game RESTART. Verify against the Glulx spec §2.9 and glulxe restart semantics, then fix at the cause (preserve the file VFS across @restart; reset only what the spec says is reset) rather than adding a signal.
