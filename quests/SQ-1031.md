## The guard is a convention, and the code says so in its own words

`crates/zvm/src/screen.rs:2225`:

    pub struct V6Cell {
        pub w: u16,
        pub h: u16,
    }

    /// Guard against a zero axis reaching the divisions below. A profile that
    /// stated `0` would otherwise panic somewhere far from the mistake.
    pub fn new(w: u16, h: u16) -> Self {
        V6Cell { w: w.max(1), h: h.max(1) }
    }

The constructor states the invariant and enforces it. The struct definition makes
it unenforceable: `V6Cell { w: 0, h: 0 }` compiles, skips `new` entirely, and
reaches `y / cell.h` at `exec.rs:3275` and the sibling division at `exec.rs:4255`.

**This one panics in RELEASE as well as debug** — integer division by zero is not
a debug-only overflow check — which separates it from SQ-1030's arithmetic, where
release merely wraps.

This is CLAUDE.md's "a guard beats a convention" corollary with the roles
reversed: here a guard EXISTS and a public field routes around it. The fix is to
make the fields private with `w()`/`h()` accessors, which is breaking and
therefore free now and expensive after a release — the framing SQ-1014's ledger
is built on.

## Why it is scheduled and not started

`cell.w` and `cell.h` are read at well over a hundred sites across `zvm` and
`app`, and SQ-1009's proportional-pen lane currently has most of the `app` ones
open. Converting them now would collide with that lane on nearly every file it
holds.

Dispatch as soon as SQ-1009 lands. This is scheduled, not parked.

## Do not regex the conversion

`cell.w` is a field access that reads identically to a method call and appears
inside multi-line expressions throughout the render path. CLAUDE.md's refactoring
policy records three separate occasions where a regex sweep over Rust source here
produced code that compiled into something subtly different. Let the compiler find
the sites — privatise the fields first and fix what fails to build.

Related: SQ-1014 (the review that found it), SQ-1030 (the same class, but in
arithmetic rather than indexing), SQ-0917 (which gave the cell its own type).
