  SQ-1482 implemented §12.11's object overlays for the US Hulk; QUESTPR1.D64 carries an eighteenth ObjectInRoom record, B01250R, whose index 250 names no item (the release has 54) and which spec §12.11 does not mention. Nothing on the disk or in the database says when it is drawn, so the overlay is left OFF rather than guessed at (spec §11: name these rather than infer them). Needs a real-machine capture or emulator run of the C64 Hulk to settle.

--- note 2026-09-10T16:16:16Z ---

Rendered 2026-09-10 with our decoder: B01250R is three flat vertical bars, no drawing — value 1 at x 16..=73, value 3 at x 74..=159, value 2 at x 160..=237, all y 0..=127; bottom 33 rows unpainted. Colour bytes [50,135,232,198]: byte 50 is C64 RED per machine-screenshots/c64-hulk-chamber.png (our table says orange), 135 is blue, 232 unknown. So on the machine: red | unknown | blue bars over the upper four fifths of the picture. Reads as a full-screen effect (wash before/between pictures), a backdrop for a close-up (rooms 81-89), or a colour-adjust card — not an object. Watch for three tall bars during play.

--- note 2026-09-10T16:19:31Z ---

SOLVED by the user 2026-09-10 (machine-screenshots/c64-hulk-colorbars.png): B01250R is the "Adjust your TV to match above colors" card shown before the game starts — four 64-px bars RED, YELLOW, BLUE, GREEN, then HIT RETURN. Not an overlay: part of the boot sequence with the R01099 title card (SQ-1495). Ground truth: byte 50 red, 232 yellow, 135 blue, 198 (header byte 11, "unused" per §8.3) green for pixel value 0. Our decoder draws it as three unequal bars — decoder/variant discrepancy handed to the SQ-1491 lane. Remaining work here: draw the card at boot as part of SQ-1495's sequence, so this quest folds into that one once the colours are right.
