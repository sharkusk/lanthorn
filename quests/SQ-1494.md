  SQ-1482 implemented §12.11's object overlays for the US Hulk; QUESTPR1.D64 carries an eighteenth ObjectInRoom record, B01250R, whose index 250 names no item (the release has 54) and which spec §12.11 does not mention. It decodes to two flat colour blocks (orange and blue, one unrecognised C64 colour byte 232) covering canvas (16,0)-(240,126); the MS-DOS release of the same game does not ship it. Nothing on the disk or in the database says when it is drawn, so the overlay is left OFF rather than guessed at (spec §11: name these rather than infer them). Needs a real-machine capture or emulator run of the C64 Hulk to settle.
