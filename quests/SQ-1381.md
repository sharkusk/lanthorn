  User report 2026-09-07 with a /dump-terminal: extended mode (raster composite re-uploaded every frame, ~3 MB, 303 raster encodes, 389 uploads, 102 placements a frame) hangs the display whenever text is added or the pane scrolls; hybrid and raster work; Ghostty answered the t=s probe. PR 198's transmit_shm names the object /rtui-{pid}-{id} and StatefulKitty re-transmits under the same stable id each frame, so frame N+1's shm_open(O_TRUNC) can overwrite frame N's object before Ghostty has read it; Ghostty then reads the wrong pixels or fails "size too small"/"unable to open", and the frame is dropped until a full redraw. lanthorn's kitty_shm_write already uses a per-transmit serial for exactly this reason (SQ-1374 lane note).
