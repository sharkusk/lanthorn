Widened 2026-09-08 (user). Two halves, complementary not alternative:

1. IN-CRATE harness, in each engine crate's own #[cfg(test)] module: a hand-rolled xorshift PRNG, a few thousand random story images (valid header + random bytes, plus a few mutated real fixtures from unit_tests/), each driven through step() for a bounded number of steps with a per-story wall-clock budget; asserts no panic and the budget held; fixed seeds so a failure reproduces. Zero dependencies (zvm has no dev-deps and must stay that way). This is the regression guard: it runs under `cargo nextest` and on every CI push. Also cover restore_quetzal / restore_state and restore_screen_snapshot with hostile buffers, and gvm's Glk call surface with random arguments.

2. A separate `fuzz` workspace package (its own crate, so the engine crates' zero-dep rule holds) with cargo-fuzz targets for zvm and gvm: step-loop on arbitrary images, Quetzal/IFZS restore, screen-snapshot decode, disassembler. Run by hand on a nightly toolchain; not part of CI. Any crash it finds becomes a pinned in-crate case in half 1. Document how to run it in docs/internals.

Origin: SQ-1014's robustness pass found print_table and DisasmCache with a throwaway fuzzer in minutes; the caps landed (SQ-1395) but no harness did, and the one adversarial test in the repo (object_scan_eof) exists because czech.z5 once panicked.
