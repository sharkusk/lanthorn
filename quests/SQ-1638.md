Observed per story (any host using the mapper and item tracker would see these):
1. Anchorhead (full game): no room is detected and no inventory is detected.
2. Anchorhead Special Edition Demo: inventory IS detected, but each item carries a lot of extra description instead of its noun name. Examples: 'umbrella my green handle'; 'clothes my tasteful muted brown green ensemble clothing pants trousers shirt' (adjectives, possessives and synonym lists from the parser/dictionary run together into one item name).
3. Counterfeit Monkey: the same kind of extra wording on detected items (also many one-character items, single letters and digits, which the host now hides in its own list).
4. Superluminal Vagrant Twin: rooms are detected when the player issues the 'map' and 'prospects' commands, i.e. the output of these meta commands is being mistaken for a room description/header, creating bogus rooms.
Expected: a detected room only from a real location change; item names reduced to the noun the game prints in inventory/room lists (no possessives/adjective/synonym tails); Anchorhead's status/inventory formats recognised. Repro with each story from the host's story folders.
