Add a headless walkthrough regression suite. Pick about 8-12 games from the gitignored stories/, masterpieces/ and treasures/ folders, covering z3, z5, z8, z6 (e.g. Journey, Zork Zero, Arthur, Shogun), Glulx with graphics and sound, a Blorb with sound, and Scott Adams. For each:
- a complete command script from a reliable source (the IF Archive's solutions directory, published walkthroughs). Keep scripts out of the repo when their licence doesn't allow copying, and load them from a local path.
- drive the game through the library session API to its winning ending;
- assert the final score and ending text, and no panic, hang or runaway.
Also exercise save, restore and restart partway through each game, and check the mapper and hints don't error along the way. Skip (not fail) when a story file or script is absent, as the existing media-gated tests do. Keep a normalized transcript per game, so any host can compare its own run of the same script against it.
