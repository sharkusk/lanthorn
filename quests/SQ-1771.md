--- note 2026-10-11T17:11:38Z ---

Design settled with user 2026-10-11 (replaces the idiom-table idea). When a turn changes room and no plain direction explains it (and it is not already a relocation: death, travel-to "go to X", restore/undo), restore the shadow probe to the state BEFORE that turn and: (1) control: send `look`; if the shadow lands in the destination, the move was independent of the command (timed event) -> record nothing more, stay a relocation. (2) else try n,s,e,w,ne,nw,se,sw, then u,d, then in,out (nautical words only for a story whose vocabulary has them), first landing in the destination room wins; (3) confirm the winner by replaying it once more from the same pre-turn state and requiring the same room (guards shadow-only random relocations). On a confirmed match, place the passage under that direction (word = the direction word the game accepted). No match -> stays unplaced. Off the main thread via crate::probe, like return_probe. Real-game tests: Zork I climb tree / climb down, Adventureland climb tree, a non-reproducible move stays unplaced, a timed-event relocation on `wait` stays unplaced.
