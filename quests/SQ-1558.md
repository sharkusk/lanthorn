Current code (rev a64394b5):
- crates/app/src/config.rs:2394 `pub fn resolve(cli: &Cli) -> Config` is the only way to get the merged defaults < config file result. `Cli` (config.rs:~236) is a clap `Parser`; a host that isn't a command line has to depend on clap and build one via `Cli::try_parse_from(["lanthorn", "--user-dir", dir])` just to name the directory.
- `BackgroundTidy`'s config spellings (`off`/`every_room`/`on_overlap`/`debounced`) exist only inline in `write_config_at` (config.rs:~2767); a host showing that setting has to round-trip serde to convert.

Change:
- Add `pub fn resolve_at(user_dir: &Path) -> Config` (or `resolve_file(path)`), sharing the body with `resolve` so both stay one code path; `resolve(&Cli)` becomes a thin wrapper that works out the path from the CLI and then applies CLI overrides as now.
- Give `BackgroundTidy` public `as_key()` / `from_key()` (or `FromStr`/`Display`), used by `write_config_at` and the reader.

Acceptance:
- Test: `resolve_at(dir)` on a temp dir with a config.toml equals what `resolve` returns for `--user-dir dir` with no other flags; a missing file yields defaults.
- Test: every `BackgroundTidy` variant round-trips through `as_key`/`from_key`, and `write_config_at` output is unchanged.
- TUI behaviour unchanged.
