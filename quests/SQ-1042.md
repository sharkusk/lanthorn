## The idea

Complete input from the objects actually PRESENT, read from the live object tree,
rather than from a static word list.

`zvm::location::object_tree_view` and `find_player_object` already give this: walk
from the player to the current room and its contents, plus inventory, and you have
exactly the set of nouns the game would itself accept here. `dictionary::lookup`
maps a candidate to the word the game stores, truncation and all.

## Why it does not spoil

**It names only what the game would list if asked.** Anything in the room
description or in `INVENTORY` is already public knowledge; completing it saves
typing rather than revealing anything. The line to hold is CONCEALED objects — a
thing in a closed container, or one whose "visible" attribute is clear, must not
appear, or completion becomes a puzzle solver. Get that filter right first; it is
the whole difference between a convenience and a cheat.

This is the feature that most directly fixes what ages these games worst: the
guess-the-noun tedium, where you can see the thing described and cannot find the
word for it.

## Design notes

* **Adjectives matter.** `take rusty` and `take knife` may both be needed when two
  knives are present; completion should offer the disambiguating adjective, which
  means reading the object's full name property rather than just its short name.
* **Complete nouns before verbs.** The verb set is small and learned quickly; the
  noun set changes every room and is where the friction is.
* **Existing precedent.** `crate::complete` already exists for slash commands and
  `keyboard-nav-conventions` says an autocomplete intercept must fall through
  rather than hardwire a fallback, and that Shift-Tab reverses any Tab-cycler.
  Follow those; this is a second consumer of an established interaction, not a new
  one.
* Off by default, or at least trivially toggled — some players will consider it
  assistance they did not ask for.

Better with SQ-1040's grammar table (which noun slot a verb expects), but unlike
SQ-1041 it is genuinely useful without it.
