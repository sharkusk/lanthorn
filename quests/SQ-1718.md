  Story files compiled with the community ZIL toolchain (ZILF + ZAPF) get no automap: rooms are detected (v3 global 0, crates/zvm/src/location.rs current_location, same rooms as Infocom's own build) but the SQ-1579 gate (crates/app/src/host/boot.rs:1496-1497 and host/reset.rs:456-457 via engine_helpers.rs:300-301 zmachine_story_has_no_grammar) disables mapping because zvm::grammar::Grammar::load fails with BadVerbTable. Two independent causes in crates/zvm/src/grammar.rs, both must be fixed: (1) detect_format (580-603) guesses InformGv1: a ZILF build's serial is the build date (e.g. 261005, which passes the Inform-shaped-serial test since only a leading 8 is excluded) and ZAPF writes the signature "ZAPF" at header $3C-$3F, read as an Inform version byte >= '6'. (2) configure_classic (678-689) assumes the verb table starts at static memory base and that verb_count = (first verb data - base)/2; ZAPF puts the dictionary at the static base and other tables between the verb pointer array and the first verb's data (example: Zork I compiled from the MIT-licensed source at github.com/historicalsource/zork1, ZILF 0.11.1: static base/dictionary $2C18, verb table $4416, 136 pointers ascending $477A..$5059, array ends $4526; per-verb data is standard Infocom fixed format). The action/preaction/preposition tables likely don't directly follow the grammar data either. Fix ideas: locate the verb table structurally (verb count from the dictionary's verb numbers 255 down, pointers that lead to valid syntax data) instead of assuming the static base; don't take a non-digit $3C-$3F ("ZAPF") as Inform, or fall back to the Infocom formats when the Inform read fails; and narrow the SQ-1579 gate so only a positively absent grammar (not any parse error) disables the map. Repro: compile historicalsource/zork1 with ZILF 0.11.1 (zilf zork1.zil && zapf zork1.zap), play look/open mailbox/north/east/open window/enter house/west: Infocom r88 maps 5 rooms, the ZILF build 0; skipping the gate maps the same 5. Other Grammar::load users (verb/vocabulary features) are presumably affected too.
