  ifdb_documents.rs classify (~147-175) treats any extension not on its exclusion list (~132) as a text document when IFDB says format text/document, and RemoteZip entries (~387-404) accept any extension, so launcher/script types (.bat .cmd .vbs .js .hta .lnk .url .command .terminal .fileloc .desktop .jar …) can be saved as documents. documents::entry_for (~431) sets display_name to the stem, so 'Manual.pdf.bat' shows as 'Manual.pdf'. Hosts that open documents with the system's default app need the real type visible and only viewer types offered. Suggest an allowlist (pdf, images, txt/md/rtf/html-as-text) and display names that keep the extension.

--- note 2026-10-07T20:01:19Z ---

User decision 2026-10-07: allowlist (pdf, png/jpg/jpeg/gif, txt/md/rtf, html/htm; zip as a container whose members pass the same allowlist); anything else is not downloaded or listed; display names keep the extension. Raised to high: the system opener (cmd /C start on Windows) would execute e.g. Manual.pdf.bat shown as 'Manual.pdf'.

--- note 2026-10-07T20:03:03Z ---

User amendment 2026-10-07: non-allowlisted extensions whose bytes sniff as text (e.g. .sol solution files) are kept as Text documents, shown only in the internal pager, never passed to the system opener; a never-keep list of executable/launcher extensions (bat, cmd, ps1, vbs, js, hta, lnk, url, sh, command, jar, …) is refused even when the content is text.
