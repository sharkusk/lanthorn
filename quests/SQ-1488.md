--- note 2026-09-16T22:51:24Z ---

Implemented: license check redone independently (crates.io + GitHub tag v0.9.20/commit 493f840, both LICENSE-MIT/LICENSE-APACHE read in full; note the module layout in main branch has drifted from published 0.9.20 — the published crate is a flat unpacker.rs, no packer_name field, and does use a packer_signatures.rs byte-pattern table purely to NAME a cruncher + apply one ALZ64/Kabuto compat patch, not to drive decompression). Dependency added to crates/blorb (blorb::depack, default-features=false) per coordinator override. blorb::depack::depack_c64_prg wraps regenerator2000-core's unpacker; wired into app::hints::scott_disk_stories (auto-recognizes depacked Scott bytes exactly like any other disk) and a new crunched_program_name refusal path in read_story_file, distinguishing "could not unpack" from "unpacked but unrecognised dialect".

Result on the six real specimens: 5/6 depack successfully (default 50M-instruction budget) and recover REAL legible game text ("QUESTPROBE-ONE by Scott Adams", "ADVENTURE INTERNATIONAL", "Commodore version by: Mak Jukic, Version: 1c", item descriptions like "Mirror/MIRR/") — proving the depacker genuinely works. But none of the five resolve to a playable scott::Database: this Hulk C64 release uses Adventure International's OWN driver layout, distinct from scott::c64's Mysterious Adventures layout (SQ-1455) and not a bare S.A.G.A. database at the fixed offset scott::saga_us checks. The 6th disk ("THE INCREDIBLE HULK - THE ADVENTURE.D64") genuinely fails to depack even at 40x the default instruction budget (2 billion, still incomplete) — a real regenerator2000-core limitation on that specimen, not a lanthorn gap.

So SQ-1488 is complete under its own stated fallback ("depack them... or at least refuse by name as a crunched program") — all six now refuse by name with an honest, specific message instead of the old generic "no story file" — but NONE of the six are actually playable yet. Filed a follow-up quest for the new-dialect reader (the bigger, separate reverse-engineering task). Test suite: crates/app/tests/suites/sq1488_c64_crunched.rs (wired into the `engines` group binary), including a positive assertion that depacking recovers real legible text (not just "didn't error").
