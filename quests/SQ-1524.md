--- note 2026-09-16T17:59:25Z ---

Scope narrowed 2026-09-16: SQ-1496 solved and shipped the family-C (bitmap) side's (usage, index) table for all three titles (Voodoo Castle, The Count, Claymorgue Castle) — that half of this quest's title is done, see SQ-1496's own note and commit ff7c4143. What remains here is ONLY the family-D line-art index (Adventureland, Pirate Adventure, Mission Impossible, Strange Odyssey) — where each per-room record after the shared LINE_ART_OFFSET opening picture belongs.

SQ-1496's method is a strong template to reuse directly: it found the table on the PROGRAM disk (side A), not the picture disk, located by a marker byte pattern, and settled every entry by cross-referencing decoded pictures against the game's own room text and the same titles' already-solved builds on other platforms (Apple II scrambled/plain releases already have per-room associations worked out — check `apple_pictures.rs`/`saga_us.rs` for what's already known about these same four games on Apple II, since that's the same cross-platform anchor SQ-1496 used).
