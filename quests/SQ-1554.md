Citations crates/app/src/, as of af51457d.

Current: `command_band::verbs_from_grammar` (render/command_band.rs ~490) returns the story's grammar verbs; the band shows them alphabetically. `BUILTIN_VERBS` / `default_verbs` (~449) are only the fallback when there is no grammar. `refresh_band_data` (host, SQ-1549) passes the same flat list to other hosts.

Change: return verbs ranked, with a tier per verb, so any front end can show the useful ones first and the rest behind a "More" affordance:
1. Core tier — the verbs nearly every parser game needs (a curated list in the lib, e.g. look, examine, take, drop, inventory, open, close, put, go/enter, wait, read, push, pull, turn, give, talk/ask/tell — intersected with what this story's grammar actually accepts, and mapped to the story's own spelling/synonym).
2. Story tier — verbs this story's grammar has that its own text uses or prompts (words the game prints, e.g. from room descriptions and messages — the same decoded text SQ-1553 needs), plus verbs the player has already used successfully this session.
3. The rest — everything else in the grammar, alphabetical.
Within a tier, a stable order (core by the curated order; others alphabetical). Keep synonyms folded under one representative verb where the grammar maps them to the same action (show one of `get/take/carry`), with the others available.
Expose the tier in the band data (SQ-1549's host API) so a non-terminal host can render its own "More…"; the TUI's band can show tiers too (its layout is its own call).

Acceptance
- On Zork I / Mini-Zork: the core tier is small (roughly 10-20 verbs) and contains take/drop/open/examine/look; synonyms like get/take collapse to one entry; verbs the game's text mentions rank above unused ones; the full list is still reachable.
- Games with no grammar table keep today's fallback behaviour; existing suites pass.
