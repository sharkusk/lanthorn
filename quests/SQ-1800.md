2026-10-18 diagnosis (pty capture, 80x28 kitty, 90s): the menu genuinely animates — 255 transmits at ~2.8/s, 0 adjacent identical payloads, a 7-frame loop, 0.01–0.9% of pixels changing per frame. Same image id re-transmitted (replaced in place); the one superseded id is deleted; nothing accumulates. No defect, no code change. Remaining cost: a full 65–72 KB compressed frame per tick (~175 KB/s) — delta frames would be a separate feature.
