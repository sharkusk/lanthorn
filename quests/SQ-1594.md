--- note 2026-09-26T04:14:03Z ---

render/upper_window.rs left-aligns and clips a grid wider than its pane (:195 grid_content_x_span, :276-278) and follows the cursor horizontally (:316-322) so an in-place form stays usable on a narrow screen. A host drawing grid windows itself can reproduce the clip but not the cursor-following offset, which is private. Wanted: a public helper, e.g. grid_viewport(upper, area, cursor, show_cursor) -> first visible column (and clip width), so every host scrolls a wide form the same way. Example: Bureaucracy's licence form on a narrow screen.
