--- note 2026-09-25T19:50:45Z ---

**Repro (rev d7fd62b7).** Boot `Journey - The Quest Begins.adf` (Amiga r30) and answer 11 key reads with Enter. The 11th, right after "…or in what manner, I could not know.", picks Praxix → Cast → Elevation. Two more Enters print "Praxix thought to cast the "Elevation" spell…". The map now holds one room, "journey, the following was written in ", which is object #79.

**Path (not the mapper crate).** `crates/zvm/src/location.rs`, `detect_location_v6` (l.558), rung 3, returning `StatusName`:
- The only status candidate is the Amiga's centred "JOURNEY" title on the top rule row above the story window (`v6_status_candidates`, l.485).
- Rung 3 (~l.581) runs `global_room_by_shown_text` (l.619). That accepts candidates that aren't left-anchored, guarded only by `V6_GLOBAL_ROOM_MIN_LEN` = 6 (l.592), and "journey" has 7 letters.
- Global 153 = 79. That's Praxix, a party member, and only while he is the selected character. One of his properties is a packed string starting "journey, the following was written in".
- `object_text_property` (l.678, match ~l.692) accepts it via `status_name_matches` (l.720), because "journey" is a word-boundary prefix.
- The detected location clears when the global does, but the room stays mapped.

**Why only the Amiga release.** PC r83 paints no band above its story window (which starts at y=1), so it has no candidates. `location.rs:241-243` notes exactly this for Journey, and the Amiga release breaks that assumption.

**Nothing decides "don't map this story".** The mapper starts as soon as `detect_location` returns Some. Per-game `show_map` (`styles.rs:56`, read at `host/boot.rs:626`) only hides the map at boot. The TUI runs the same path, so it maps the same room.

**Change (both):**
1. Rung 3 must not accept a candidate that isn't left-anchored (a centred title banner), and must match the whole property text rather than a prefix.
2. A menu-driven v6 story with no grammar (`Grammar::load` is `Absent`) shouldn't be mapped at all.

**Acceptance:**
- The repro above leaves the map empty for the Amiga release.
- PC r83 is unchanged (no map).
- Zork Zero, Arthur and Shogun still detect and map their rooms exactly as before.
