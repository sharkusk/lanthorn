Current code (rev a4c90be0):
- With the Menu plan, `V6FrameInputs::bottom_anchor_menu` (crates/app/src/render/screen.rs:~2879) moves every menu-band run down by `extension` rows (`bottom_anchor_menu_runs`, screen.rs:7544-7566), and the story box grows into the gap.
- The only published canvas→game mapping, `RasterFrame::game_px` (crates/app/src/render/v6_layout.rs:~2654, via `canvas_to_game_axis`), treats every canvas row at or beyond `native.1` as an added extension row and returns `None`. Rows above that are mapped unshifted, so a band that straddles `native.1` would even get the wrong game row.
- The TUI doesn't hit this: its hybrid keeps a private click map for the band (screen.rs ~1183-1185, recorded with the `menu` scale when `plan_is_menu`, then graphics.rs ~818 `V6ClickMap::map_click`). None of that is available to a host.

Evidence (1000×848 pane):
- Journey PC r83 in Hybrid: native 640×400, canvas 640×528. A click on "Start" at canvas (28,456) is dropped (`game_px` → None). In Raster, canvas 640×400, the same control at (28,328) advances the menu.
- `Journey - The Quest Begins.adf`: same pattern ((28,440) dropped in Hybrid, (28,312) works in Raster).
- Every Journey menu click is lost in a host's Hybrid whenever the pane has spare height.

Change: publish the inverse for frames composed with `bottom_anchor_menu`. For example, a `game_px` on the composed `V6Frame` (or on `V6HybridPlan` together with the extension) that:
- maps band rows back up by `extension`;
- maps rows above the band as today;
- returns `None` for the story-extension rows.

It should share one rule with the TUI's `V6ClickMap` so they can't drift.

Acceptance:
- Journey r83 and the Amiga release on a tall pane with the Menu plan: the canvas centre of "Start", "Proceed", "Cast", a character name and "[cancel]" each maps to the same game pixel the game drew it at. Delivering it through `deliver_v6_click` advances the menu exactly as the TUI does.
- A click in the story-extension gap maps to `None`.
- Frame/Extend/Letterbox frames are unchanged.
