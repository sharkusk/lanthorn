Citations crates/app/src/, as of 5560bc25. The data these features need already reaches the host (seen_words, seen_nouns, scope_words refreshed per turn at host/turn.rs:735-739; dict_words at boot host/boot.rs:1348); what is missing is the logic, which sits in bin or crate-private code.

1. Completion: `input::recompute_suggestions` (input.rs:3950, pub(crate); 3 tiers scope > seen > dict, cap 6, slash-command branch) and `apply_completion` (input.rs:3925, private). Expose a host API: candidates for a given input line + caret (the same ranking and cap), and the resulting line after applying candidate i — so a host can show them its own way (ghost text / list) with identical results. `render::transcript::ghost_completion` (render/transcript.rs:1705, pub(crate)) shows what the TUI treats as "the rest of the word"; expose the pure part.
2. Reveal: `reveal::arm` (reveal.rs:239) reads visible text from the TUI's wrap caches (`visible_text`, reveal.rs:396). Add a variant that takes the visible text (lines) as input and returns the words to light (the token filter at reveal.rs:300-316 as a pure fn), still honouring the guidance switch. Expiry stays the host's business.
3. Guidance switch: the `/set-guidance [on|off|auto]` handler (slash_dispatch.rs:643, bin) persists per game. Provide a host function that sets it with the same per-game persistence and returns the effective value.
4. Command band data: `command_band::refresh_verbs` (:535) and `refresh_objects` (:710) are pub but only the bin calls them (loop_tick.rs:485). Provide a host-level entry that refreshes and returns the band's data as plain values — verbs with their `VerbLine` shapes and `VerbSource`, quick words/compass, objects here / carried / seen, preposition objects — without `CommandBandState`'s cell layout (column_rects, PanelSlide).

Acceptance
- TUI unchanged (it calls the same functions); existing suites pass.
- Headless tests: candidates for a partial word match the TUI's ranking on a real story (skip when absent); applying a candidate rewrites the line as Tab does; reveal from supplied text lights the same words as the TUI for the same text; setting guidance persists across a reboot of the session; the band data for Zork I lists grammar verbs with shapes and room/carried objects.
