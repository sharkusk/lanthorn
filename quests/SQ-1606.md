--- note 2026-09-26T19:14:58Z ---

TerminalFacts::min_story_screen (SQ-1596) raises the pre-boot screen, and SQ-1602 carries it through @restart. On a live resize (host::screen::set_story_pane) a host with a minimum still has to find the smallest pane that gives the game N×M itself: host::boot::min_terminal_size_for_story_floor is pub(crate). Wanted: publish that search, or let set_story_pane apply the session's stored min_story_screen floor, so resize, boot and restart all use the lib's arithmetic.

--- note 2026-09-26T23:34:45Z ---

Follow-up: the published min_terminal_size_for_story_floor (host/boot.rs:375) searches for a TERMINAL size. It goes through pre_boot_host_screen and compute_pane_layout, which always reserve a help-bar row, and it applies the Z-machine's arithmetic to Glulx too, adding a gutter column. A host that already has a story pane (the unit set_story_pane takes) can't use it without adding and removing that row itself. Wanted: a pane-level version (smallest story pane giving the game N×M, per engine), or have set_story_pane apply the session's stored min_story_screen floor itself.

--- note 2026-09-27T03:52:03Z ---

Second follow-up, after trying fa089b1a: min_story_pane_for_floor (host/screen.rs:191-207) doesn't fit a host that also seeds TerminalFacts::min_story_screen at boot. Its Z-machine branch probes candidate panes through declared_story_screen_dims (render/screen.rs:528-563), which floors cols at boot_screen_cols. Because boot_story's own pre-boot raise (host/boot.rs:871-886) already made boot_screen_cols meet the floor, every probe passes, and the search returns the real, unraised pane. The HEADER is right: the game is told at least N columns, and that now comes free. But a host that sizes its own grid from the returned pane gets one narrower than the game's declared screen, so it clips the game's grid. Wanted: a mode that answers 'which pane gives the game N×M' from the unfloored story_screen_dims for cols, i.e. the pane a host must lay out at so nothing clips, distinct from the header guarantee. Repro: Bureaucracy booted with min_story_screen (40,19) at a 30×19 pane; min_story_pane_for_floor(…, (30,19), (40,19)) returns (30,19), but the host needs (41,19).
