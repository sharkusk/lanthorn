## Partly done in the 0.3 cut (commit `6ffd7413`) — four of six landed

Added and shooting clean: `debug-inspector`, `maze-grid`, `multi-window-layout`,
`scott-adams-graphics`, plus `macintosh-embedded-face` for SQ-1016's fallback
face. `docs/native-font.png` is new. Ten README stills regenerated.

### The two that did NOT land, and why it is structural

`story-list` and `cover-gallery` want a LIBRARY launch, and the harness resolves
`media` as a FILE — `Provenance::read` mounts it through `load_mounted_story`,
which reads bytes — so a directory fails provenance and the shot skips on every
run for ever. They were written, run, observed skipping, and then REMOVED rather
than left in: a permanently skipping shot reads as coverage without being any,
which is SQ-1015's vacuous-green problem wearing a different hat.

What they need is for the harness to understand a library launch. Note also that
a directory launch trips the first-use "set this as your default story
directory?" prompt, which reads a LINE from stdin before the terminal is touched
at all — so whatever drives it must answer that first (an empty line is "no").
That part is already solved; the file-vs-directory resolution is not.

### Three findings from the regeneration worth keeping

1. **Half-blocks cannot carry a raster frame.** It resolves the composite into
   cells — one sample per column, two per row — so 1280x800 becomes ~130x86 and is
   blown back up. Artwork survives, TYPE smears into illegibility. This had been
   true of the committed `arthur-amiga-proportional` shot since SQ-1009: a frame
   whose whole subject is a typeface, captured through the one backend that cannot
   show one. Both raster shots are kitty now. Same root fact as SQ-0978's inert
   pixel lock.
2. **Adventure's v8 port defeats the mapper.** It prints no room-name header, so
   `maze-grid` pointed at it produced `Main(0)` — an empty table. Moved to Zork I.
   Worth knowing before anyone else reaches for `advent.z8` as a map fixture.
3. **Two key specs were answering a prompt, not the game.** Adventure asks
   "Would you like instructions?" and Counterfeit Monkey "Can you hear me?" before
   either takes a command. The shots' own `expect` guards caught both.

### Left imperfect on purpose

`macintosh-embedded-face` sits on a `[more]` pager. Extra terminal rows do not fix
it — the v6 window's row count is the GAME's, not the pane's — and the frame
already shows eight crisp lines of the face with correct letter spacing, which is
what it exists to prove. Not worth holding a release for; worth a better key spec
later.
