--- note 2026-10-03T15:35:44Z ---

Follow-up to SQ-1703 for hosts that draw in real pixels (not terminal cells). Today such a host must own these itself:
1. Aspect-preserving fit: the lib offers only the stretch (per-axis) mapping, which in a pixel host distorts the art (~25% at 1280x800). Offer, alongside the stretch: given the pane in pixels, the uniformly scaled frame size and offset.
2. Readability fallback: let a host ask whether a design-size layout leaves the main text window readable at a given screen (a minimum characters-told threshold), and own the rule for falling back to cell layout — re-decided only when the pane, text cell or setting changes, never on the game's own relayout (Photopia's chapter cards squeeze the text window to nothing on purpose). The TUI could use the same rule on a small terminal.
3. Mask image: expose GlkMask::opaque(x, y) or a ready-made alpha image of the mask, for hosts that apply it per pixel (today a host calls cell_coverage once per pixel).
4. Expose the primary text-buffer window id on GlulxSession (hosts walk the window tree to find it).
