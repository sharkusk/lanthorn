--- note 2026-10-03T15:35:44Z ---

Follow-up to SQ-1703 for hosts that draw in real pixels (not terminal cells). Today such a host must own these itself:
1. Aspect-preserving fit: the lib offers only the stretch (per-axis) mapping, which in a pixel host distorts the art (~25% at 1280x800). Offer, alongside the stretch: given the pane in pixels, the uniformly scaled frame size and offset.
2. Readability fallback: let a host ask whether a design-size layout leaves the main text window readable at a given screen (a minimum characters-told threshold), and own the rule for falling back to cell layout — re-decided only when the pane, text cell or setting changes, never on the game's own relayout (Photopia's chapter cards squeeze the text window to nothing on purpose). The TUI could use the same rule on a small terminal.
3. Mask image: expose GlkMask::opaque(x, y) or a ready-made alpha image of the mask, for hosts that apply it per pixel (today a host calls cell_coverage once per pixel).
4. Expose the primary text-buffer window id on GlulxSession (hosts walk the window tree to find it).

--- note 2026-10-03T15:49:57Z ---

Revised item 1 (owner decision 2026-10-03): the default for a design-size story is to STRETCH it to the screen (aspect ratio not preserved), as the TUI does today. Preserving the aspect ratio should be an option, not the default. Please add it as a setting with both modes, for the TUI and for hosts:
- a config key (global + per-game, like glk_design), e.g. glk_design_fit = "stretch" (default) | "aspect"; "aspect" scales the frame uniformly to the largest size that fits and centres it, the remaining area painted like outside-the-mask (glk_mask_outside);
- host-level calls for both mappings that work in pixels as well as cells: given the pane, the frame's size/offset and each window's rectangle, and click mapping back to design pixels, for the selected mode;
- the TUI gets the aspect mode too (letterboxed in cells).

--- note 2026-10-03T15:56:30Z ---

DECISIONS (owner, 2026-10-03):
- Item 1: glk_design_fit = "stretch" (default) | "aspect"; global key in config.toml (templated) + per-game sidecar (per-game wins). Also add a global glk_design key (today per-game only). Aspect = uniform scale computed in device pixels, frame size/offset snapped to whole cells in the TUI, centred, leftover painted glk_mask_outside; mask applies inside the frame. One value carries mode + pane + unit (px or cells) for both TUI and pixel hosts: frame size/offset, each window rect, click -> design px. Existing stretch fns unchanged.
- Slash command `set-glk-fit [stretch|aspect|auto]` modelled on set-v6-render (bare toggles, auto = inherit global, persisted per-game); reuse the v6 render border icon (render/controls.rs BorderControl::V6Render) as the toggle.
- Applies ONLY when a <story>.cfg is found AND it contains WindowWidth+WindowHeight; otherwise normal cell layout, the icon is hidden and the command says the game has no design size. No manual design-size key.
- Item 2 (readability fallback): TUI adopts it too; threshold = main text window told >= 40 cols x 10 rows; re-decided only on pane / text cell / setting change, never on the game's own relayout.
- Items 3 (mask opaque(x,y)/alpha image) and 4 (primary text-buffer window id on GlulxSession) as filed.
Plan: step A = items 1, 3, 4 + command + icon; step B = item 2 on top of A.
