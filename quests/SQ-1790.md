--- note 2026-10-14T23:26:50Z ---

Today (crates/app/src/complete.rs completion_candidates, at bf540aee): const SUGGESTION_LIMIT = 6; scope words first (suggest(&[], scope_words, partial, 6)), then a merge of the flat dictionary and recently printed words, deduplicated, stopping at 6. Tab/Shift-Tab (TUI) and any host's cycling can only reach those 6. Example: The Hitchhiker's Guide to the Galaxy (z3), typing 'lo' — the dictionary has lobby, lock, long, loose, lounge… and 'look' can fall past the sixth, so it is never offered.

Wanted:
1. No cap on what can be cycled to: every match is a candidate (Tab/Shift-Tab, Ctrl-N/P cycle through all). How many rows a list SHOWS is the frontend's business (the TUI might keep showing 6 and scroll; a host may scroll its own list). Keep a cheap path for hosts that only want the top N (an optional limit parameter is fine).
2. Ranking that puts the likely word first, so the inline ghost (the first candidate) is usually right:
   - First word of a command (verb position): the game's common verbs first — look, examine/x, take/get, drop, inventory, open, close, read, go and the compass directions, wait, again, etc. — then words the player has typed in earlier commands (history), then the rest.
   - Later positions (object position): words for what's here (scope) first as now, then recently printed and typed words, then the dictionary.
   - Within a tier, prefer shorter / more frequent words over alphabetical order where it helps (so 'lo' → look before lobby).
   Abbreviated dictionaries (z3's 6-letter words like 'examin') keep working as now.
3. Hosts get the candidates in that order through the existing completion_candidates (or a new fn with a limit/positional context), and the TUI's own suggestions use the same ranking so the two can't drift.

Tests: 'lo' at the start of a line offers 'look' first in a z3 game whose dictionary has lobby/lock/long/look; cycling reaches every match; object position still puts scope words first; a typed-before word ranks above an unseen dictionary word.
