--- note 2026-09-27T00:41:37Z ---

GameSession::line_key_terminator (session.rs ~5302) says whether the game lists an arrow or F-key as a line terminator. The terminal binary adds one more rule on top: arrows are withheld from V6 stories unless config v6_arrow_keys is on (default off), in main.rs 97-121 (forward_arrow_to_v6 / withhold_arrow_from_v6). A host that calls the library can't follow that rule without copying it. Wanted: the rule in the library, for example line_key_terminator taking the config (or &AppState), or a host-level helper that decides and submits a line key the way deliver_v6_click does for clicks. Then every host treats arrows at a line read as the terminal does.
