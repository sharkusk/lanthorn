  glk_cfg::resolve_borderless (~132-141) resolves per_game, then garglk.ini, then the Glk design file, then borders on. There is no user-wide default, so a player who prefers borderless windows must set it game by game, in the TUI as in any host. Add an optional user default (a config.toml key such as glk_borderless, and a parameter on resolve_borderless for hosts) that sits below the game's own garglk.ini/design so an author's choice still wins, above the built-in default.
