--- note 2026-09-25T20:05:03Z ---

Current code (rev d7fd62b7): FMV Poker's full-screen canvas story window accumulates runs in `BufferWindow::px_runs` and never prunes them: 56 runs after 4 hands and still growing, many of them "HOLD" labels later covered by blank runs. Drawing them in order into a raster is correct, but a host that exposes runs as real text (selectable, read by screen readers) ends up with invisible stale words under the art.

Change: drop runs that are wholly covered by later runs or erases in the same window, or expose, per run, whether it's still visible in the composite, so the list reflects what's on screen.

Acceptance:
- FMV Poker after several hands: the run list holds only visible text (the current HOLD labels), and its length stays bounded.
- The Rasterise output is unchanged.
