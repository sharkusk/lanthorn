Citations crates/app/src/ and crates/*, as of af51457d.

Observed: completion candidates (complete.rs), the command band's VERB / WHAT columns (render/command_band.rs data: verbs_from_grammar, refresh_objects) and vocabulary offers show dictionary entries as stored — truncated to 6 Z-characters in Versions 1-3 (ZMSD §13.3) and 9 in v4+ (§13.4): `activa`, `brandi`, `examin`. Matching already accounts for truncation (vocab.rs `truncated` ~303-331, complete.rs ~208, test at complete.rs:465), so typed full words work; only the display is truncated.

Change: a per-story expansion table from dictionary entry to full display word, built once at boot, used wherever an entry is shown to the player (completion candidates and ghost tail, command-band verbs/nouns, offer words):
1. Primary source — the story's own text: decode the story's static text (the high-memory strings and abbreviations, object short names, any string the game can print) once, tokenise with the story's own rules, and map each truncated entry to the full word(s) whose truncation equals it. Use it when exactly one full word maps to the entry.
2. Fallback — an English lexicon for words the game never prints (typically verbs such as `activate`): the verb-synonyms crate's forms, or a bundled word list, again only on a unique match.
3. Ambiguous or unknown -> keep the truncated form (never guess). Inserting a full word is always safe: the parser truncates it to the same entry.
Glulx/Inform 7 dictionaries (longer keys) and Scott Adams (short words) need only the no-op path unless their keys truncate too — check.

Acceptance
- A v3 fixture (Mini-Zork / Zork I when present): completion for `activ` offers `activate` if the story or lexicon supports it; the band's verbs show full words; `examin` -> `examine`; an ambiguous prefix stays truncated; applying a completion still reaches the right dictionary entry.
- TUI: completion ghost and command band show the full words; existing suites pass; boot-time cost measured (decode once) and reported.
