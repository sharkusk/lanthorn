Citations crates/app/src/, as of af51457d.

1. Rename a Save State. `persist_files.rs` has no rename; `list_saves` (persist_files.rs:38) shows `Meta::name` over the file name. A host with a saves list has to open the archive and rewrite meta.json itself (validating through `archive::Meta` and keeping unknown fields). Add `persist_files::rename_save(path, new_name)` (atomic rewrite of the name in the archive's meta, and the file name if the naming rule ties them), used by the TUI's saves manager too if it gains rename.
2. A "no pictures" launch choice. `LaunchOverrides` (launch_options.rs:71) can name a picture archive but cannot say "none" — so a host can't offer "None, text only" for a graphical story. Add an explicit text-only override (e.g. `PictureOverride::None`) that boot honours (no picture source; v6 falls back to its text path where the story allows), and list it in the launch dialog's choices.
3. Frontispiece discovery. The Blorb `Fspc` chunk (the cover) isn't reflected in `ChunkInfo` or `StoryMeta`, so a host can't tell whether a Blorb has a cover without reading it; it has to offer a cover URL for any Blorb with pictures and fall back on a miss. Add a flag (or the frontispiece's picture number) to `StoryMeta`/`ChunkInfo`, filled during the scan that already reads the Blorb.

Acceptance
- Tests: rename round-trips (listed name changes, contents intact, restore still works); a launch with the text-only override boots a picture-bearing story with no picture source; a Blorb with an Fspc chunk reports its frontispiece in StoryMeta, one without reports none.
- TUI unchanged otherwise; existing suites pass.
