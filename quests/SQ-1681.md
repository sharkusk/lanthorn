Decisions 2026-10-02 (maintainer):
- The Documents panel is a TAB in the new Journal (see the Journal quest filed alongside), not a standalone panel. Build order: Journal first (Map/Room/Inventory tabs), then this tab, then Hints.
- Text and images are shown INSIDE lanthorn:
  - text in a scrolling pager, rewrapped to the pane, handling CR-only (old Mac) line endings and non-UTF-8 bytes (Latin-1/CP437-era files);
  - PNG/JPEG/GIF through the existing image backend (kitty/sixel/halfblocks);
  - PDFs go to the system viewer, or an OSC 8 file:// link.
  - Spoiler-flagged files confirm before opening.
- Text detection by CONTENT, with or without a .txt extension (zorkI.step1, sample.from.zork). No NUL bytes, mostly printable; tolerate CR/LF/CRLF and high-bit bytes.
  - It must be a SHARED public function for hosts, e.g. `documents::sniff_kind(path or bytes) -> DocKind`.
  - documents::list's DocEntry.kind should use it instead of extension-only classification.
  - SQ-1680's eligibility for extensionless links stays IFDB-format based (nothing is downloaded yet), but saved files get re-classified by content.
- Open: which keys switch tabs (Alt+1..5 if free); whether a second tab can be docked under the Map on tall screens (deferred, not v1).
- The web agent may add requirements before dispatch.
