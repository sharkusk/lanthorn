--- note 2026-09-24T17:11:28Z ---

Citations crates/app/src/export_svg.rs (and mapper), as of af51457d.

Current: `is_portal = matches!(conn.exit_dir, Direction::Up | Direction::Down)` at export_svg.rs:998 and :1216; `ConnectorLayout.is_portal` (~1112) is what a host reads from `layer_layout`. `planar_region` already treats Up/Down/In/Out/Unknown as portals when deciding layers (mapper layer.rs), so the map's own notion of a portal is wider than the layout flag.

Change
1. Set `is_portal` for every non-compass exit — Up, Down, In, Out, and the other non-planar kinds (Unknown / named or custom exits, whatever `planar_region` stops at) — using one shared predicate (ideally the same one planar_region uses) so the layout, the layer logic and the renderer agree. Expose which kind it is (up/down/in/out/other) so a host can badge it.
2. In the SVG export (`render_svg_body` / `render_svg_of` / `render_svg_layered`), draw portal connectors with a dotted stroke (round-capped dots, visibly different from the existing dash used for conditional/gated or distorted passages), compass connectors solid as today. Keep the portal glyph/badge.

Acceptance
- Tests: a fixture with an In and an Out passage on one layer yields `is_portal` connectors with the right kind; the byte-level layout/SVG correspondence test still holds; the SVG output styles portal paths dotted and compass paths solid; gated passages keep their dash.
- TUI unchanged except where it reads the shared predicate (its cell renderer draws portals as icons already).

--- note 2026-09-24T17:12:00Z ---

Addition (owner): in the SVG export, a connector END whose direction is up/down/in/out/other must not get the normal compass arrowhead; only ends with a real compass direction (n/ne/e/se/s/sw/w/nw) keep one. A pure up/down passage has no arrowheads (its portal glyph carries the direction); a passage that is east one way and up the other keeps the arrowhead at its east end only. Expose the per-end direction kind in layer_layout so a host applies the same rule; test pure-portal, mixed and compass-only connectors.
