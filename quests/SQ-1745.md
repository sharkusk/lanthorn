Cause: hints::story_supports_hint (hints.rs:580) only checks the dictionary for 'hint'. It sets HintSession::builtin_hint (host/hints.rs:156), and hints_tab.rs:42/726 draws BUILTIN_LINE above any running hint sidecar.
Repro: Beyond Zork r57-s871221 with bzorkizm.z5 beside it. Open hints: the companion runs, and the panel also says to type HINT. In the story, HINT prints only '[If you're really stuck, maps and InvisiClues(TM) Hint Booklets are available...]'.
Ask: recognise the stock booklet notice (or known builds with real hints), and leave the suggestion out while a sidecar runs. Add a test against r57, skipped when the file is absent.
