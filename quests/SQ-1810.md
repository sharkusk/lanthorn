DECISION (owner, 2026-10-23): option 1, a block shift. A run of consecutive hard-broken lower-window lines that start with spaces and fit within the told width forms a block. When the block's furthest right edge (indent plus length) passes the pane width, shift the whole block left by that overflow, capped by the block's smallest indent. Lines that still overflow wrap as today. The shift is recomputed at render time and never stored in the transcript. A block that already fits is untouched, and a pane wider than the told width changes nothing (no re-centring). AMFV r77 at 45 columns: indents 22/23/39 become 10/11/27. Rejected: scaling each indent by pane/80, trimming each line separately, stripping all padding. Measure first by decoding every string in the fixed-80 stories, looking for a newline followed by 4 or more spaces, and use the hits as specimens.
