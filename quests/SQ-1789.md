--- note 2026-10-14T21:59:01Z ---

Today (crates/app/src/state.rs, HintSession::apply_turn ~97-120, at 814b6218): on result.erase_lower the transcript is truncated back to clear_anchor, and the FIRST clear sets clear_anchor = transcript.len(). So everything printed before the first clear is kept for good, and every later clear only removes text after it.

Example: a typed-in InvisiClues booklet for The Hitchhiker's Guide to the Galaxy (hhgginv.z5, by Paul David Doherty) prints an introduction and a 'Sample Question' (Fire Fungus) before its first erase_window. That text then sits above every clue opened afterwards, in the TUI's hint panel and in any host that shows HintSession.transcript. On a real interpreter the clear wipes it.

Wanted: a screen clear (erase of the lower window) clears everything shown, the first clear included, so what's visible is only what the program printed since its last clear. If older text should stay reachable, keep it as scrollback (scroll up), not on screen; or simply drop it, whichever fits the panel's design. Hosts reading HintSession.transcript should get the cleared view (or a clear boundary they can use).

Tests: a program that prints an intro, clears, prints a menu, then a clue; after each clear the visible transcript holds only the text since that clear.
