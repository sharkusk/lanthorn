--- note 2026-09-27T19:41:26Z ---

crates/app/src/history.rs: TurnSummary (~85) has turn, command and map_changed but no location. record_turn (~36) stores a map snapshot only when the structure changed, so map_at_turn (~73) returns an older snapshot whose current room is the one current when that snapshot was taken. Example: minizork, a turn 'east' into the Kitchen (no new rooms) shows the you-are-here marker on South of House. The terminal's replay map (main.rs ~709) has the same problem.
Ask: record the player's room per turn (e.g. TurnRecord::location: Option<RoomId>, plus its name), expose it on TurnSummary, and offer 'the map at turn N with that turn's current room' (or document that a host sets the current room from the summary). A host's timeline can then also show 'Turn N: command · room'.
