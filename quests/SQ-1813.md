Detail: crates/app/src/hints_tab.rs:64 `fn min_cols_for(program: Option<&str>) -> u16` picks HINTS_MIN_COLS_IZM (60) for an *izm file stem, else HINTS_MIN_COLS (72). Both constants are public but the choice between them is private, so a host that boots hint companions through host::hints with its own panel size has to restate the stem rule. Asked: make it pub (ideally re-exported from app::host next to the hint-companion entry point), so hosts floor exactly as the TUI does and pick up any future change to the rule.
