--- note 2026-10-09T16:31:31Z ---

Cause: host::hints::open / open_with_tuid (crates/app/src/host/hints.rs:176) / start / start_with_tuid boot the companion Z-machine with GameSession::new, which passes no host_screen, so it always starts at the 80x24 default. No entry point takes a screen size.
Calling Engine::set_screen_dims after boot only half works: with bzorkizm.z5 at 40 columns the menus redraw, but the title keeps its boot-time centring ('Beyond Zork: The Cocon', cut off) and a question's hint screen garbles ('s beak. How can I get it?'). The program reads its width at boot.
Ask: add an optional (rows, cols) to these entry points, passed to GameSession::new_with_trace's host_screen, and resize on a later panel resize the way the story pane's sync_zvm_screen_dims does. The TUI's hint panel (hints_tab.rs:718-731) could then lay the program out to the panel instead of clipping its 80-column grid.
