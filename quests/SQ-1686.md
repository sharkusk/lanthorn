--- note 2026-10-02T22:19:40Z ---

ifdb_documents.rs (c6ae9805, ~line 196) sets DocumentOption.spoiler only from the URL path: path.contains("/solutions/") || path.contains("/hints/"). Lost Pig's IFDB record links its walkthrough as ifarchive.org .../walkthru.txt with the label "Walkthrough — Competition version", outside those folders, so it is offered as a normal document (pre-ticked in any chooser that ticks non-spoilers by default).

Ask: also mark a document as a spoiler when its file name or its IFDB link title/description/label says so: e.g. case-insensitive words walkthrough, walk-through, walkthru, solution(s), hints, hint, cheat(s), invisiclues, answers, spoiler(s), "how to win"; including entries inside a zip (ZipEntry) by their file names. Keep the URL-path rule. Avoid false positives such as "hint" inside unrelated words (match whole words or the stems above) and the game's own manual (e.g. "Hints for new players" in a manual title is a judgment call: prefer flagging, since a host leaves spoilers unticked but still offers them).
Tests: Lost Pig's walkthru.txt link is a spoiler; a zip entry named solution.txt is a spoiler; a manual.pdf is not; the existing path tests still pass.
