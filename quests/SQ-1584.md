--- note 2026-09-25T20:05:04Z ---

Current code (rev d7fd62b7): the TUI's `render_story_pane` draws Hybrid as the full raster composite on some screens:
- no story window, with a painted ground (crates/app/src/render/screen.rs ~l.1665, SQ-0711, e.g. Scopa);
- a picture takeover, `picture_takeover_reason` → `art_paints_anything` (~l.6007, e.g. FMV Poker's full-screen canvas story window).

`V6HybridPlan` (SQ-1574) doesn't carry this decision. A host drawing Hybrid itself (chrome runs as text in its own fonts) therefore restyles those screens' labels and buttons in its own font, which the TUI never does.

Change: add the fall-through to the host-facing plan, e.g. `V6BottomPlan::Raster` or `V6HybridPlan { raster_fallback: Option<Reason> }`, computed by the same function the TUI uses.

Acceptance:
- Scopa's table and FMV Poker's table report the raster fall-through.
- Scopa's Help/Credits and FMV Poker's opening text screen don't, and Extended grows there as today.
- Zork Zero, Journey, Arthur and Shogun report their existing plans.
