## The report

> "i typically run mac arthur from the InfocomMasterpieces.img, which contains a
> bunch of games. you may want to add a command line arg to select individual
> stories from there (or you need to use the story list like I do)."

A volume with several stories on it can only be opened one way today: launch it and
pick from the story list. There is no way to name the story on the command line, so
**nothing headless can reach any story on such a volume except whichever one the
mount happens to return first.**

## Why it is worth doing beyond convenience

It cost a real diagnosis. SQ-1063 had a Macintosh Arthur flank defect that only the
reporter could see, because `flank_shape`, `hint_probe` and `pty_capture` all boot a
path and `stories/InfocomMasterpieces.img` boots **Zork Zero** (release 296 / serial
881019). The measurement was only possible at all because the reporter separately
supplied `stories/arthur.sit`, and even then it had to be unpacked by hand
(`unar`) to get at `STORY.DATA` and `PIC.DATA` — which is a different press from the
one the defect was reported on, so the two are not interchangeable evidence.

CLAUDE.md's own rule is that a finding must name the exact fixture and release, and
a volume we cannot address by story makes that impossible for every story on it but
one.

## Shape

Something the instruments can pass through, e.g.

```
lanthorn "stories/InfocomMasterpieces.img" --story ARTHUR
```

or the `volume:inner/path` spelling the auto-resume note already uses informally
(`InfocomMasterpieces.img:InfocomMasterpieces/ARTHUR`). Note that spelling is NOT
currently understood — `app::hints::load_mounted_story` returns
`NotFound` for it, which is worth checking before adopting it as the syntax.

Whatever it is, `pty_capture`, `hint_probe` and `flank_shape` should be able to pass
it straight through, since being unable to reach a press headlessly is the actual
cost.

## Related

An `--archive` boot already exists for picking a RENDITION
(`flank_shape --archive stories/zork0.cg1`), so there is a precedent for naming the
art; this is the same idea for naming the story.
