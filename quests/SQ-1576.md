--- note 2026-09-25T17:43:51Z ---

Current code (rev 7ec7c5e5), crates/app/src/render/screen.rs:
- `fill_menu_flank_extension(&mut canvas, story, native, frame.canvas_h, cell)` (fn at l.7513, called at l.3323) extends the flanks into the rows the Menu plan opens by sampling the canvas.
- Under `V6TextMode::RecordOnly` it samples BEFORE any run's background block is painted into the canvas (a host paints those itself from the run list). Journey's vertical divider beside the story is a reverse-space run, so the fill doesn't carry that rule down the extension rows. Under `Rasterise` the block is painted first, so the rule is carried.
- Measured on Journey r83 at a 1000×848 pane: RecordOnly vs Rasterise differ exactly at x 232–239, rows 304–527 (1664 px) — the divider column. A host drawing RecordOnly shows the divider stopping at the game's story bottom instead of running down to the bottom-anchored menu.

Change: make the extension fill see run-painted blocks in both modes — e.g. paint the runs' background blocks (not glyphs) into the canvas before `fill_menu_flank_extension` under RecordOnly too (blocks are art, not text), or have the fill extend a block run's column from the run list rather than from canvas pixels. RecordOnly must still leave glyphs out.

Acceptance:
- Journey r83 (and `Journey - The Quest Begins.adf`) on a tall pane with the Menu plan: the RecordOnly canvas plus the host-drawn runs equals the Rasterise canvas pixel for pixel, including x 232–239 down to the menu.
- Zork Zero / Shogun / Arthur (Frame/Extend) unchanged; the existing pixel-for-pixel cases stay green.

--- note 2026-09-25T17:52:56Z ---

Owner addition (2026-09-25): Journey releases differ in how they draw their frame and dividers — some use REVERSE-SPACE fill (e.g. PC r83 `journey-r83-s890706.z6`, reverse-space divider runs), others use LINE-DRAWING characters (e.g. Amiga r30 `Journey - The Quest Begins.adf`; also check the Apple II builds `Journey.po` / `Journey.2mg` / `journey_s1..5.dsk`). The fix must handle both, and the acceptance must cover at least one reverse-fill release and one line-drawing release, each on a tall pane with the Menu plan, compared against the TUI's hybrid of the same frame.
