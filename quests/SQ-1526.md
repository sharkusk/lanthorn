  User asked after seeing the Atari line-art work: it's fixed at native 160x96 resolution with no scale parameter, unlike family-B's PictureList::rasterise_at(scale). Confirmed by reading code: LineArtCanvas hard-codes CANVAS_WIDTH/CANVAS_HEIGHT everywhere with no supersample. Atari's primitives (dual fill semantics, five fill patterns, colour-pair pixels across two bitmaps, animation frames, a recolour-replay pass) are richer than family-B's PictureOp (just Line/Fill), so folding into the shared PictureList type isn't a clean fit — user chose to give LineArtCanvas its own self-contained scale parameter instead, mirroring c64.rs's internal approach rather than sharing code with it.
