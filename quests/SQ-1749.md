--- note 2026-10-09T14:37:13Z ---

Cause: host::boot seeds only the mapper (host/boot.rs:1871), not state.current_room_name. sync_current_room (host/turn.rs:158, SQ-1710) covers restore, resume, rewind and restart but not a fresh boot.
Effect: engine_helpers::save_summary (:117-127) records no location for a Save State or exit autosave made before the first turn (host/persist.rs:45), though Engine::current_location() already knows the room.
Repro: boot Savoir-Faire and Save State (or quit) before typing anything: Meta.location is None.
Ask: call sync_current_room at the end of the fresh-boot path.
