Implemented on branch worktree-agent-a4c38af8a5eb59aef (0ee6d2b6, corrected by 12a3a48d). Key findings for the spec half (all in scott-dialects-spec.md Appendix A items 12-16):
- §4.6's "two numbers, and no more" is ZERO on ZX: the driver's pointer block is the nine words AFTER the header's twelve counts (plus a tenth address in word 0, the picture pointer), so the field order is derived by scanning all four §4.5 Mysterious orders at every address and keeping the one whose ten spans land (exactly one survives per title, all Early; none in the nine control snapshots), and the verb/noun split is read (each block has its own pointer, each exactly words+1 cells).
- §6.4/§9.3's SECOND PERSON is wrong for ZX as well as C64: not one second-person string occurs in any of the eleven images; the driver's first-person block (with tape prompts) sits around $64C1. `Database::second_person` was written and then removed.
- §6.4's "the visible-objects heading must be supplied on ZX" is wrong: `Things I can see:` is in the file ($66BA in Golden Baton).
- §6.1's "every ZX release stores exactly 82 messages" is wrong (only Arrow of Death 1; the eleven spread 65-99). Word length 4 IS constant.
- §4.5's "word 0 is not a field" is wrong on ZX (it is the picture pointer); §4.2's "up to 27 all-NUL cells" is 47.
- Two crate bugs found in passing and fixed: `Presentation::C64` ignored the Wording table for the room line and the "can also see" heading, and `Wording::room_prefix`'s you_are form was "You are " rather than "You are in a ".
