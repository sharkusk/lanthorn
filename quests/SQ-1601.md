--- note 2026-09-26T17:21:39Z ---

host::screen::set_glk_cell_px (SQ-1598) resizes the live Glk graphics canvases but leaves state.glk_cell_px, the value a later @restart boots with, unchanged. A host that changes its cell size (for example a text-size change) then restarts at the stale boot-time cell. Wanted: the setter updates that field too, so hosts don't write it themselves.
