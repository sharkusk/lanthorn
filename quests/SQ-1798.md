Add .github/ISSUE_TEMPLATE/: (1) lanthorn-bug.yml, 'Bug in Lanthorn (the TUI)', label lanthorn; (2) golden-lanthorn-bug.yml, 'Bug in The Golden Lanthorn (the desktop app)', label golden-lanthorn (labels on a form are fixed, hence two forms rather than a dropdown). Each form: a textarea with id 'summary' (render: text) for the /report-bug summary (or the app's Report a problem summary), so a link like issues/new?template=golden-lanthorn-bug.yml&summary=<urlencoded> prefills it; 'What happened' and 'What you expected' textareas; 'Steps' optional; a note to attach the full report file (drag it in). (3) config.yml: blank issues off; contact links to Discussions (questions, 'is this a bug?') and to goldenlanthorn.com support for players without a GitHub account. Create the two labels. The Golden Lanthorn shares this repo's engines and mapper, so its game and map bugs are fixed here; app-only bugs are fixed in the app.
