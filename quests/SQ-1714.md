--- note 2026-10-04T17:16:41Z ---

A game-driven turn (key, timer, mouse or hyperlink input applied through host::turn::apply_game_driven_result, crates/app/src/host/turn.rs ~1186; the clear is marked ~1196; TUI caller main.rs ~3271) records no TurnRecord, so TurnRecord::cleared (turn.rs ~726-732, set only by finish_command_turn) never notes a clear made on a key. history::rebuild_clear_anchor then finds none, and a rewind (resume_from_turn) past that point revives the scrollback the game wiped — in the TUI too. Repro: Narcolepsy: wake up, press a key (the game clears the dream), look, go to kitchen, then rewind to 'look': the dream text is back. The sq1712 rewind test passes only because it finishes the key with finish_command_turn. Proposal: keep a pending 'cleared' flag that the next recorded turn picks up (anchored at that record's start), or record game-driven turns that clear.
