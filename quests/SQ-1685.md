--- note 2026-10-02T21:29:33Z ---

Decisions (maintainer, 2026-10-02):
- TAB ONLY. Retire the modal hints panel; open-hints switches to (and shows) the Journal's Hints tab.
- Input focus follows the ACTIVE window, as in the web version. Clicking in the hint session's area makes it receive typed keys; clicking the story pane gives them back to the story's input line.
- The active window wins, with a visible focus indicator: styleable, e.g. a highlighted input row or cursor shown only in the focused one.
- Keyboard users also need a way to move focus without the mouse: a registry command plus a default key (to decide; not plain Tab, which autocomplete owns). Esc from the hint input returns focus to the story.

--- note 2026-10-02T21:30:44Z ---

Keyboard focus resolved: no new key needed. Today Tab on an empty prompt (or with no suggestions) is Action::ToggleFocus between Focus::Game and Focus::Map, and Shift-Tab is CycleFocusBack (input.rs; tests ~:6209-6240). With the Journal: Tab on an empty prompt moves focus to the Journal's active tab, which on the Hints tab is the hint session's input row. Tab on an EMPTY hint input returns focus to the game (symmetric). Esc also returns. Mouse click focuses whichever window is clicked.

--- note 2026-10-02T22:08:30Z ---

CORRECTION to the "Keyboard focus resolved" note above, which was wrong: Tab does NOT toggle focus to the map. AppState::cycle_focus (state.rs ~:5083) cycles only the story pane and the debug inspector's windows. The map was deliberately removed as a focus stop in SQ-0599, because the same arrow key silently meant "edit the command line" or "pan the map" with no on-screen cue; the map is now modeless (Shift+Arrow pans, the mouse does the rest). The Journal (SQ-1684) kept that unchanged, so there is no Journal focus stop.

So the Hints tab still needs a keyboard focus design, and it must respect SQ-0599's lesson: focus must be VISIBLE and unambiguous. Options to decide: make the hint session's input row a Tab stop only while the Hints tab is shown, with a clear focus indicator, giving story -> hints input -> (debug windows) -> story; or a dedicated command/key. The mouse rule (the clicked window wins) and Esc-returns-to-story stand.
