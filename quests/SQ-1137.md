## Verified, not suspected

The only production call site is `crates/app/src/turn.rs:295`:

```rust
if !should_exit {
    app::input::offer_layer_suggestion(state, mapper);
}
```

and the sole guard inside `offer_layer_suggestion` is
`if state.any_modal_overlay_open() { return; }`. `grep show_map
crates/app/src/turn.rs` returns nothing, and nothing in that path consults it.

So a player who has turned the automap OFF is still shown a modal asking *"Give
these rooms their own layer?"*, about a pane they cannot see, interrupting the
game they can. It is a question they have no way to evaluate — the dialog names
rooms and a passage, and the map that would make sense of them is hidden.

## The fix, and why it is a one-line guard rather than a queue

The tempting shape — hold the suggestion and raise it when the map is next shown
— **cannot work.** `observe_inner` sets `self.pending_suggestion = None` at the
top of every move, and the field's own doc says why:

> Transient and derived — never persisted, and replaced by every move, because a
> suggestion is about the crossing that produced it and a stale one describes a
> step the player has already walked away from.

So the next move destroys it whatever the caller does.

Dropping it is already established as safe, by `offer_layer_suggestion`'s own doc:

> Dropping one costs nothing, because nothing is written down until the player
> answers, so the same crossing raises it again.

Only the ANSWER persists (`MapGraph::seam_decision`), so an unanswered seam keeps
asking. The consequence is exactly the wanted behaviour: the question returns when
the player opens the map and walks that seam again — which is the first moment
they could sensibly answer it.

## Scope

Small, and it should not grow. The guard belongs at the offer, not at the
detector: detection is part of observation, and SQ-0785's standing decision is
that hiding a view must not degrade the data behind it. What must be suppressed is
the *interruption*, not the noticing.

While in here, check whether any OTHER map-originated interruption has the same
gap — a toast, a status line note, a recentre nudge. This one was found by asking;
nothing guarantees it is the only one.

shape, that the turn path never asks whether anyone can see the map, but that one
is invisible where this one demands an answer).
