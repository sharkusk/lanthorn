--- note 2026-09-27T02:23:31Z ---

gvm records a Glulx game's line terminators (gvm/src/glk.rs:3547 set_line_terminators, :3558 is_line_terminator), but GlulxSession has no line_key_terminator and no submit-with-terminator (a line event carrying the keycode in val2), and host::input::deliver_line_key_terminator returns None for any non-Z-machine session (host/input.rs:150). A host can't end a Glulx line read on a listed F-key or arrow as it now can for Z-machine (SQ-1610). Wanted: GlulxSession equivalents, with the shared helper extended to Glulx, following Glk's keycode rules.
